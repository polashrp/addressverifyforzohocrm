Overview

This extension automatically verifies US addresses in your Leads, Contacts, and Accounts modules. It enriches each record with geographical data and time zone information.

📌 Note: Verification is optimized for US addresses. Non-US addresses are skipped to conserve resources.

Fields Created by This Extension

The extension creates the following custom fields in your Zoho CRM. These fields all use the prefix addressverifyusaforzohocrm__.

Display Name Zoho CRM API Field Name Field Type Description
Address Status addressverifyusaforzohocrm__Full_Address_Status Picklist Verification status: Verified, Invalid, Missing, Outside US
County addressverifyusaforzohocrm__County Text County name from the verified address
County FIPS addressverifyusaforzohocrm__County_FIPS Text County FIPS code (US Census)
Customer Timezone addressverifyusaforzohocrm__Customer_Timezone Text IANA time zone name (e.g., America/New_York)
Address Details addressverifyusaforzohocrm__Address_Details Text Area Detailed verification information
Data Quality Score addressverifyusaforzohocrm__Data_Quality_Score Decimal Score from 0–100 based on field completeness
Quality Tier addressverifyusaforzohocrm__Quality_Tier Picklist Excellent, Good, Fair, Poor
Duplicate Flag addressverifyusaforzohocrm__Duplicate_Flag Checkbox Indicates if potential duplicates exist
Duplicate Count addressverifyusaforzohocrm__Duplicate_Count Number Number of potential duplicates found
Duplicate Details addressverifyusaforzohocrm__Duplicate_Details Text Area Details about duplicate records
Last Verified Date addressverifyusaforzohocrm__Last_Verified_Date Date/Time When the address was last verified
💡 Important: When referencing these fields in Zoho CRM reports, workflows, or custom functions, always use the API Field Name (the second column above), not the display name.

How Address Fields Are Detected

The extension automatically detects standard Zoho CRM address fields. Here are the field names it looks for:

📍 Standard Address Field Mapping

Address Component Zoho CRM API Field Names (in order of priority)
Street Address Street, Address, Mailing_Street, Other_Street
City City, Mailing_City, Other_City
State State, Mailing_State, Other_State
ZIP / Postal Code Zip_Code, Mailing_Zip, Other_Zip, Postal_Code
Country Country, Mailing_Country, Other_Country

📍 Latitude & Longitude Field Detection

Field Type Zoho CRM API Field Names (in order of priority)
Latitude Latitude__c, Lat__c, LAT__c
Longitude Longitude__c, Lon__c, LNG__c

If no standard field is found, the extension will look for any custom field containing "lat" or "lon"/"lng" in its API name.

Using Custom Address Fields

If your organization uses custom field names for addresses, you can modify the field detection logic in the extension's custom functions. The relevant functions are:

  • addressverifyusaforzohocrm.detectAddressFields — Controls which fields are used for Street, City, State, Zip, and Country.
  • addressverifyusaforzohocrm.detectLatitudeField — Controls which field is used for Latitude.
  • addressverifyusaforzohocrm.detectLongitudeField — Controls which field is used for Longitude.
📌 To customize:
  1. Go to Setup > Developer Space > Functions in Zoho CRM.
  2. Find and edit the function you want to modify.
  3. Add your custom field API names to the appropriate list in the function.
  4. Save the function.

For example, if you have a custom field called Custom_Street_Address__c, you would add it to the streetFields list in the detectAddressFields function.

Example: Adding a custom street field
streetFields = {"Street", "Address", "Mailing_Street", "Other_Street", "Custom_Street_Address__c"};

Frequently Asked Questions

What API names do the extension's fields use?

All fields created by this extension start with addressverifyusaforzohocrm__. See the table in the Fields Created section for the complete list.

How do I find the API name of a field in Zoho CRM?

Go to Setup > Customization > Fields, select the module, and look at the API Name column.

Can I use these fields in reports?

Yes! All extension fields are available in Zoho CRM reports. Use the API field names (with the addressverifyusaforzohocrm__ prefix) when building reports.

What if I'm using different address field names?

You can customize the field detection in the extension's functions as described in the Using Custom Address Fields section above.
