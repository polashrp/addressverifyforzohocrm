Overview

This extension automatically verifies US addresses in your Leads, Contacts, and Accounts modules. It enriches each record with:

  • Latitude & Longitude — For mapping and territory planning
  • County — For regional analysis and reporting
  • Customer Time Zone — So you know the best time to call or email
  • Data Quality Score — To prioritize data cleaning efforts
📌 Note: Verification is currently optimized for US addresses. Non-US addresses are skipped to conserve API usage.

How It Works

The extension uses the Geoapify Geocoding API to verify and enrich addresses. Here's the flow:

  1. Trigger: A workflow rule fires on record creation or update in Leads, Contacts, or Accounts.
  2. Check: The function detects if the address is in the US. If not, it skips verification.
  3. Verify: It calls Geoapify to standardize the address and get latitude/longitude.
  4. Enrich: A second call to Geoapify Reverse Geocoding gets the time zone.
  5. Update: The record is updated with all new fields and a status (e.g., "Verified", "Invalid", "Missing").
💡 Tip: You can manually trigger verification by editing a record and saving it, or via the "Run" button on the workflow rule.

API Configuration & Customization

The extension is built with Geoapify as the default address verification service. Here's everything you need to know about the API integration.

Current API Service

Service API Endpoint Purpose
Geoapify Forward Geocoding https://api.geoapify.com/v1/geocode/search Address verification, standardization, and coordinates
Geoapify Reverse Geocoding https://api.geoapify.com/v1/geocode/reverse Time zone lookup and additional address details

How to Modify the API Key

To use your own Geoapify API key (or switch to a different provider), follow these steps:

  1. Locate the Custom Function: Go to Zoho CRM Setup > Workflow Rules, find the "US Address Verification - Leads" rule, and click on the associated Custom Function.
  2. Find the API Key Variable: Look for the line where apiKey is defined. By default, it looks like:
// In the verifyAddressWithGeoapify function
apiKey = "YOUR_GEOAPIFY_API_KEY";
  1. Replace with Your Key: Replace "YOUR_GEOAPIFY_API_KEY" with your actual API key.
  2. Save and Test: Save the function and test with a record to ensure it works.
⚠️ Important: Keep your API key secure. Do not share it publicly. Use environment variables or connection settings if available.

Switch to a Different Address API Provider

If you prefer to use a different geocoding service (e.g., Google Maps, OpenCage, or US Census), you can modify the function. Here's how:

// ============================================
// FUNCTION: verifyAddressWithYourProvider
// PURPOSE: Replace this with your preferred API
// ============================================
function verifyAddressWithYourProvider(street, city, state, zipCode, country)
{
    // Step 1: Build your API URL with the correct format
    fullAddress = street + ", " + city + ", " + state + " " + zipCode + ", " + country;
    
    // Example: OpenCage Geocoder
    apiKey = "YOUR_OPENCAGE_API_KEY";
    url = "https://api.opencagedata.com/geocode/v1/json?q=" + encodeUrl(fullAddress) + "&key=" + apiKey;

    // Step 2: Make the API call
    response = invokeUrl
    [
        url: url
        type: GET
    ];

    // Step 3: Parse the response based on your provider's format
    // This is where you adapt to the new API's response structure
    if(response.get("status") == "OK")
    {
        results = response.getJSON("results");
        if(results.length() > 0)
        {
            result = Map();
            result.put("success", true);
            
            // Example: Extract coordinates (OpenCage format)
            geometry = results.get(0).getJSON("geometry");
            result.put("latitude", geometry.get("lat"));
            result.put("longitude", geometry.get("lng"));
            
            // Extract address components
            components = results.get(0).getJSON("components");
            result.put("county", components.get("county", ""));
            result.put("state", components.get("state", state));
            result.put("city", components.get("city", city));
            result.put("zip", components.get("postcode", zipCode));
            
            result.put("status", "Verified");
            return result;
        }
    }
    
    // Return error if something failed
    errorResult = Map();
    errorResult.put("success", false);
    errorResult.put("error", "Address not found or API error");
    return errorResult;
}
📌 Important Notes:
  • Each API provider has a different response format. You must adapt the parsing logic accordingly.
  • Make sure your new provider returns latitude, longitude, and time zone (or you'll need a separate time zone API).
  • Update the API key in a secure location, preferably using Zoho's connection settings.
  • Test thoroughly with various address formats before deploying to production.

Using Connection Settings for API Keys

For better security, store your API key in Zoho's connection settings:

// Instead of hardcoding the API key, use a connection
connection = zoho.connection.get("geoapify_conn");
apiKey = connection.get("api_key");

// Then use it in your API call
url = "https://api.geoapify.com/v1/geocode/search?text=" + encodeUrl(fullAddress) + "&apiKey=" + apiKey;
💡 Pro Tip: If you plan to switch API providers frequently, create a wrapper function that abstracts the API call. This way, you only need to change the wrapper logic, not every function that uses it.

Setup & Configuration

1. Install the Extension

Find the extension in the Zoho Marketplace and click Install. Follow the prompts to authorize it for your CRM.

The extension adds several custom fields to your Leads, Contacts, and Accounts. Make sure they are visible on your layouts:

addressverifyusaforzohocrm__Data_Quality_ScoreScore from 0–100 based on field completeness

3. Workflow Rules

The extension includes workflow rules for each module. You can find them under Setup > Workflow Rules. They are named:

  • US Address Verification - Leads
  • US Address Verification - Contacts
  • US Address Verification - Accounts

Each rule is triggered on Create or Edit and calls the corresponding verification function.

Using the Features

Address Autocomplete

When you type an address in a Lead, Contact, or Account, the extension suggests completions using Geoapify. Select a suggestion to auto-fill the address fields and trigger verification.

Batch Verification

To verify a large number of existing records, use the BatchVerifyAddresses scheduled workflow. It runs weekly on Sunday at 2 AM and processes records with missing or outdated verification.

You can also run it manually from the workflow rule page.

Map View

In the Related List of a module, you'll find a Map View tab that plots all records with latitude/longitude. Click a marker to open the record in CRM.

Data Quality Dashboard

A custom dashboard widget shows key metrics:

  • Total records and verification rate
  • Quality score distribution (Excellent / Good / Fair / Poor)
  • Timezone distribution across your customers
  • Duplicate records count

Frequently Asked Questions

Why are non-US addresses skipped?

To optimize API usage and costs. The extension is designed for US addresses, but we may expand coverage in the future.

How do I update an existing record?

Simply edit and save the record. The workflow rule will trigger and re-verify the address.

What happens if an address is invalid?

The status is set to "Invalid" and the record is not enriched. You can review the error message in the Address_Details field.

Can I change the Geoapify API key?

Yes, update the apiKey variable in the Custom Functions. See the API Configuration section above for detailed instructions.

Can I use a different address API provider?

Yes! The extension is designed to be flexible. You can replace the Geoapify calls with any geocoding service that returns latitude, longitude, and address components. Refer to the API Configuration section for a code example.

How do I test if the API is working?

Create a test lead with a valid US address (e.g., "1600 Amphitheatre Parkway, Mountain View, CA 94043"). Save it and check if the status field updates to "Verified" and the latitude/longitude fields are populated.
