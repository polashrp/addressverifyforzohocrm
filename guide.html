📥 Installation Guide

Step 1: Install the Extension

  1. Go to Zoho Marketplace
  2. Search for "Address Verify & Customer Timezone"
  3. Click Install
  4. Follow the installation wizard
  5. Grant necessary permissions

Step 2: Set Up Workflow Rules

Module Workflow Name Trigger
Leads US Address Verification - Leads On Create / On Edit
Contacts US Address Verification - Contacts On Create / On Edit
Accounts US Address Verification - Accounts On Create / On Edit
📌 Note: Workflow rules are created automatically when you install the extension. If you need to modify them, go to Setup > Workflow Rules in Zoho CRM.

Step 3: Add Custom Fields to Layouts

  1. Go to Setup > Customization > Modules and Fields
  2. Select each module (Leads, Contacts, Accounts)
  3. Click the Layouts tab
  4. Add the extension's custom fields to your layout
  5. Save your changes

❓ Frequently Asked Questions

Does this work with non-US addresses?

No, this extension is specifically designed for US addresses only. Non-US addresses are automatically skipped.

Do I need to configure field mapping?

No, the extension automatically detects your CRM's standard address fields. If you use custom field names, you can modify the detection logic in the Custom Functions.

Can I verify addresses manually?

Yes! Use the "Verify Address" button on any record, or edit and save a record to trigger the workflow.

Can I verify both Billing and Shipping addresses?

Yes, for Accounts, both Billing and Shipping addresses are verified separately.

How do I run reports?

The extension includes a dashboard widget that shows verification stats, quality scores, and time zone distribution. You can also run reports using Zoho CRM's standard reporting tools.
